🔗 **Live : [benjaminbayle.tech](https://benjaminbayle.tech)**

---

## ✨ Fonctionnalités

- **Présentation** – Hero stats (Root‑me, certifications, homelab), bio, CV interactif  
- **Parcours** – Timeline double (études / expériences) avec missions détaillées  
- **Projets** – Switch Blue Team / Red Team, 7 projets cyber (dont 2 en cours)  
- **CTF** – 9 challenges (Pentest, OSINT, CTI & Reverse) – flags, timer, validation SHA‑256, indices  
- **Homelab** – Graphe réseau interactif (React Flow) avec 15 nœuds, détails au clic  
- **Veille** – Agrégateur RSS (8 flux : CVE, HTB, LMI, Korben, …) avec recherche et filtres  
- **Contact** – Formulaire Formspree + liens GitHub / LinkedIn

## 🛠️ Stack technique

| Technologie         | Utilisation                          |
|---------------------|--------------------------------------|
| React 18            | UI composants                         |
| Vite                | Build & dev server                    |
| Tailwind CSS + vars | Thème cyberpunk (4 palettes)          |
| Framer Motion       | Transitions et animations             |
| React Flow          | Graphe du homelab                     |
| Lucide React        | Icônes                                |
| Formspree React     | Gestion du formulaire de contact      |
| rss2json API        | Agrégation des flux RSS               |
| GitHub Pages        | Hébergement statique + CDN            |
